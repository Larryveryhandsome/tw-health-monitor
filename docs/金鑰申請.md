# 通知金鑰申請與設定教學（tw-health-monitor）

> **不設定任何通知也能用**：異常會寫在 `data/last_run.txt` 和 `data/state.json`。
> 想在手機收到提醒，再從下面挑一種（或兩種都設）。兩種都**免費**。

| 管道 | 要準備什麼 | 填在 `.env` |
|---|---|---|
| Discord | 一個 Discord 伺服器頻道的 Webhook 網址 | `DISCORD_WEBHOOK_URL` |
| LINE | Messaging API 的 Channel access token＋你自己的 LINE userId | `LINE_CHANNEL_ACCESS_TOKEN`、`LINE_TO` |

## 先做一次：建立 `.env`

1. 把專案裡的 **`.env.example`** 複製一份，檔名改成 **`.env`**。
2. 用記事本打開，把值貼在等號後面（不要加引號），存檔。
3. 測試：在資料夾開命令列執行

   ```bash
   python notify.py "測試一下"
   ```

   會印出成功的管道，例如 `送出管道： ['discord']`。

> 🔒 `.env` 不會被 git 上傳。設定檔 `config.json` 裡的 `notify` 只寫「要讀哪個環境變數的名字」，金鑰本身一律只放 `.env`。

## 一、Discord Webhook

1. 在 Discord 開一個自己的伺服器（左側「＋」→「建立我的伺服器」），或用現有伺服器裡你有管理權限的頻道。
2. 對頻道按右鍵（手機長按）→「編輯頻道」→「整合」→「Webhook」→「新 Webhook」。
3. 取個名字（例如「健康巡檢」）→ 按「**複製 Webhook 網址**」。

```
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/（貼上整串）
```

注意：**有這個網址的人就能往該頻道發訊息**。外流的話回到同一頁把那個 Webhook 刪掉，再建一個新的。

## 二、LINE 推播

需要一個 LINE 官方帳號的 Messaging API channel（免費）。如果你已經有 LINE bot，可以共用同一個 token。

### 1. 建立官方帳號並開 Messaging API

1. [LINE Official Account Manager](https://manager.line.biz/) → 建立 LINE 官方帳號。
2. 官方帳號後台右上角「設定」→「Messaging API」→「啟用 Messaging API」，選或建立一個 Provider。

### 2. Channel access token

[LINE Developers Console](https://developers.line.biz/console/) → 你的 Provider → 這個 channel →「**Messaging API**」分頁 → 最下面「Channel access token (long-lived)」→「**Issue**」→ 複製。

```
LINE_CHANNEL_ACCESS_TOKEN=（貼上）
```

### 3. 你自己的 userId（要推給誰）

同一個 channel 的「**Basic settings**」分頁最下面「**Your user ID**」（U 開頭、33 個字元）就是你本人的 userId。

```
LINE_TO=U（貼上）
```

### 4. 一定要做：加官方帳號好友

用你自己的 LINE 掃官方帳號後台的 QR code **加好友**，否則推播送不到。

### 費用與注意

- 推播（push）會算進官方帳號方案的每月訊息則數；巡檢**只有異常才推**，而且同一個異常不會每天重複推（預設每 72 小時才提醒一次，`renotify_hours` 可調；好了會推一則「已恢復」）。訊息太長會分成最多 3 則。免費方案通常很夠。實際則數以 LINE 官方公告為準。
- token 等於這個官方帳號的發訊權限，外流時回「Messaging API」分頁重新 Issue（舊的會失效）。
